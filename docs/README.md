## Dokumentenstatus

| Dokument | Version | Stand |

| Spezifikation | 2.3.0 | Freigabe ausstehend |

> **Hinweis zum Handbuch:** Das Handbuch wird vor der Implementierung als Soll-Dokumentation geschrieben. Es dient der Entwicklung als Zielbild und wird in jeder Phase mit dem tatsächlichen Verhalten abgeglichen. Abschnitte, deren Details erst in der Umsetzung feststehen (Gerätebefehle, Menüpfade, Screenshots), sind mit **⚠ Zu verifizieren** markiert.
